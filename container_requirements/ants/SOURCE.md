# ANTs brain template (OASIS)

These three files are the OASIS template used by `antsBrainExtraction.sh`
(see `tools/ants.yaml`). They ship with Skullstrip Bench so that a user only
has to bring the ANTs container and a BIDS dataset.

Source: Brian Avants and Nick Tustison, "ANTs/ANTsR Brain Templates",
figshare, doi:10.6084/m9.figshare.915436.v2, file Oasis.zip, folder
MICCAI2012-Multi-Atlas-Challenge-Data/. Redistributed unchanged under the
